# Disclosure Boundary

このリポジトリは技術的な考え方を説明するための公開サンプルです。

## 公開するもの

- Laravel の基本的なサービス分割
- 複数文書を同一ケースへ整理する考え方
- Cross-document comparison
- Finding / Evidence / Human Review の関係
- 架空データを使ったテスト

## 公開しないもの

- 顧客固有の名称・文書・業務ルール
- 実際の閾値、計算式、例外条件
- Rule Schema やルール管理の内部構造
- Prompt や Agent の具体的な処理順序
- MCP / 外部ツールの具体的な分割、名称、接続方式
- 本番 API、データモデル、認証・権限構成
- 実案件の精度、評価データ、障害事例

公開サンプルで重要なのは「どの技術を何個使ったか」ではなく、**自動処理の結果をどのように検証可能な形で人へ渡すか**です。
